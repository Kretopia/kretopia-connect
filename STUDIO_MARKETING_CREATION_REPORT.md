- **Why create a Project?** proof strip: Brief · Work · Wrap.
- **What happens after I click?** "It shapes a brief and a starting structure, you review and edit it".

## Claims audit
Every claim maps to shipped behaviour: brief extraction, tasks/deliverables, credits and invoice drafts all exist today. No autonomous-action claim is made. Banned vocabulary ("AI-powered", "AI-generated", "chatbot", "copilot", "assistant", infrastructure names, emojis) is absent from all new copy.

## Hierarchy
Promise → Create a Project CTA → voice/text explanation → product proof → existing Projects → activity blocks. With zero Projects the dashboard collapses to a single creation-led empty state, so existing work can never outweigh the creation action.
