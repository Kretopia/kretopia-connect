# Kretopia Connect

Je veux connecter ce projet à un dépôt GitHub existant : Kretopia/kretopia-app, branche main.

Ne génère pas une nouvelle application à partir de zéro — ce dépôt contient déjà le code complet et fonctionnel :

- React 18 + Vite + TypeScript

- Tailwind CSS + shadcn/ui

- Supabase (auth, base de données, edge functions)

- PWA (service worker)

Si tu peux importer directement le code depuis ce dépôt GitHub, fais-le maintenant.

Sinon, crée uniquement un projet minimal avec exactement cette stack (Vite + React 18 + TypeScript + Tailwind CSS + shadcn/ui), sans page ni fonctionnalité particulière — une seule page vide suffit. Je connecterai ensuite ce projet au dépôt GitHub existant via les réglages d'intégration GitHub du projet.
