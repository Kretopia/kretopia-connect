## Section 1 — The "Kreto · Studio" avatar, located precisely

The card is not page-specific markup — it's a single shared component, `src/components/agent/KretoTip.tsx`, mounted on **at least 10 different surfaces** via a `surface` prop that maps to an eyebrow string and a rotating set of tip lines (`Today`, `Scout`, `Studio`, `Match`, `KrePay`, `Passport`, `Clients`, `Events`, `Circle`, `Recordings`, `Studios` for the Brand dashboard). On `/desk` (Studio), it's mounted via `<KretoTip compact />` inside `CreatorWorkHome` (`src/pages/WorkHome.tsx:550`), which resolves `surface` from the current path (`match: (p) => p.startsWith("/desk")`) to `eyebrow: "Studio"` — rendering the literal text `Kreto · Studio` at `KretoTip.tsx:187`.

The avatar is `<KretoAvatar size={compact ? "sm" : "md"} />` at `KretoTip.tsx:183` — a real, deliberately-designed brand component (`src/components/brand/KretoAvatar.tsx`): a silhouette portrait image plus an animated sunset-gradient halo with five distinct motion states (idle/thinking/listening/speaking/recording), explicitly documented as "the single visual representation of Kreto... use everywhere Kreto appears." It is not a generic icon, robot, or placeholder — removing it from the component itself would remove Kreto's identity from every one of its 10+ mount points.

**Consequence for implementation:** the avatar cannot be removed from `KretoAvatar.tsx` or from `KretoTip.tsx` unconditionally — that would violate the explicit "do not remove avatars elsewhere" instruction. The removal must be conditional on the resolved surface being Studio specifically (e.g. `surface === "desk"` / `tip.eyebrow === "Studio"`), replacing just that one render path's avatar slot with a non-avatar treatment while every other surface's `KretoTip` keeps `KretoAvatar` exactly as-is. This is a surgical, single-branch change inside a shared component, not a component-wide removal.
