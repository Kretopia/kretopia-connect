## How to read the evidence columns

- **CODE** = read in this repository at `origin/main` during this pass (file and line when stated).
- **RUNTIME** = none was produced in this pass (no staging, no two-account test, no production access). Where a repository migration header states a production verification, it is quoted as *documentary*, never as mine.
- A GA finding is a hypothesis until CODE confirms it. "not inspected" means this pass did not read it; it is not a claim that it is safe or unsafe.
